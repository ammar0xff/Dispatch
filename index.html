Dispatch

QR-BASED FIELD-WORK SUPERVISION

Supervisor dispatches tasks and issues QR codes.
Field agents scan them on site to confirm work.
Both see everything live.

🧉

Agent App

Scan QR codes on site, report GPS location, view assigned tasks. Runs in the background.
🎡

Supervisor Dashboard

Generate QR codes, assign tasks, manage users, watch live locations on a map.

How it works

1
Supervisor creates a user account and generates a QR code for the agent or site.
2
Agent installs the app, scans the QR code to register, and receives assigned tasks.
3
On site the agent scans the task QR code. Location + timestamp are recorded in Firebase.
4
Supervisor sees the completion on the live map dashboard with an instant notification.
Built with Flutter · Firebase Realtime DB · Source on GitHub
